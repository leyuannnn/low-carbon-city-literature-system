# 输入

- `README.md` 与 `research-question.md`。
- 当轮 `rounds/round1/search-log.md` 或 `rounds/round2/search-log.md`。
- `vault/00-文献索引.md`、`vault/papers/` 以及相关主题和方法笔记。
- 第二轮另读 `rounds/round1/memo.md`，不得覆盖第一轮文件。

# 判断规则

1. 选择与候选方向最接近的两篇论文，并排比较研究对象、时间范围、结果指标、模型与假设、主要发现和影响可比性的差异。
2. 将“研究边际”定义为相对最接近已有研究准备额外回答的具体问题，而非宽泛的“研究不足”。
3. 候选方向必须可检验，说明研究对象、结果、比较对象或竞争性解释。
4. 第一轮末尾明确写出最可能使自己收窄或放弃方向的已有证据及对应补检办法。
5. 第二轮并排呈现原判断、补检所得、更新后的判断和理由，结论只能是保留、收窄、放弃或暂缓。
6. 引用具体论文及 PDF 页码、章节或表图；区分作者自述、本项目推断和尚无证据的猜测。
7. 列出本人必须回查的至少一处原文，并给出要核对的具体句子或表格。
8. 第二轮末尾提出下一步最小可行验证：实证题写研究对象、可观察结果、比较对象和最关键识别假设；若暂缓，说明验证如何帮助决定是否重启。

# 输出

- 第一轮：`rounds/round1/memo.md`。
- 第二轮：`rounds/round2/memo.md`。
- 本人核查建议写入当轮备忘录，实际结果另存 `vault/checks/student-source-check.md`。

# 证据不足时

明确保留疑问或暂缓方向，说明检索边界和结论适用范围。不得因结果符合预期而省略反向证据，也不得把未检索到解释为不存在。
