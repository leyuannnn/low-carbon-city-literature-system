# 输入

- 必读：`README.md`、`research-question.md`。
- 第一轮：读取用户提供的本地 PDF 清单及可访问的网络渠道。
- 第二轮：另读 `rounds/round1/memo.md`，将首轮末尾的反向证据条件转换为检索式或引用追踪路径。

# 处理规则

1. 使用实际可用的渠道，包括用户本地文献库、期刊官网、知网公开页面、国家科技文献平台、网络搜索和出版商页面。
2. 第一轮围绕“低碳城市试点”“绿色全要素生产率”“绿色技术创新”“人工智能发展”“数字基础设施”等组合检索。
3. 第二轮优先搜索首轮判断的替代解释、相反结果、相近区域或指标，以及最接近论文的参考文献和被引研究。
4. 每条记录写明检索日期、渠道及覆盖范围、完整检索式、命中和筛选结果；不能只保存最终入选论文。
5. 候选条目记录题名、作者、年份、版本、DOI 或来源链接、全文访问状态及入选/排除理由。
6. 优先以 DOI 去重；无 DOI 时结合题名、作者和年份。工作稿、学位论文与期刊版记录关系，不重复计数。
7. 网络不可用时记录错误并切换本地库；只能读摘要时明确限制，不补写全文内容。
8. 第二轮零结果、重复结果和访问受限均如实保留，不以无关论文凑数。

# 输出

- 第一轮：`rounds/round1/search-log.md`。
- 第二轮：`rounds/round2/search-log.md`。
- 将入选全文或摘要材料交给 `skills/read/SKILL.md`；将版本和访问状态同步到 `sources/manifest.md`。

# 证据不足时

明确写出未覆盖的数据库、年份、语言或引用路径，以及因此不能排除的替代解释。不得把“未检索到”写成“没有研究”。
