# 输入

- 研究问题与入选标准：`research-question.md`。
- 检索记录及入选条目：`rounds/round1/search-log.md` 或 `rounds/round2/search-log.md`。
- 原始 PDF 或其实际提取文本：`sources/extracted/<作者>/content.md`。

# 处理规则

1. 每篇笔记先写书目信息、版本、DOI/链接、全文状态和实际阅读范围。
2. 全文精读覆盖主文的问题、理论或假设、材料/样本、变量、模型与识别假设、主要结果、稳健性、异质性、结论及作者说明的局限；涉及附录结论时再读相应附录。
3. 实证研究至少检查：研究对象、结果指标、政策变量、控制与固定效应、平行趋势或动态效应、非随机试点选择、其他政策干扰、交错 DID 的处理效应异质性。
4. 区分三类内容：作者自述、表格或正文可核对的证据、本项目跨论文比较后形成的判断。
5. 关键判断标注 PDF 页码、章节或表图；数字必须核对表头、单位、显著性和样本量。
6. 若正文表述与表格不完全一致，记录差异，不替作者强行统一；将其列为第二轮或本人核查事项。
7. 只能读摘要时采用摘要级模板，不推测样本外结论、识别质量或未披露局限。
8. 论文贡献分为“作者声称的贡献”和“能由其他论文核实的相对推进”，避免照抄宣传性表述。

# 输出

- 每篇论文写入 `vault/papers/` 一个独立 Markdown 文件。
- 笔记末尾列出交给归档 Skill 的主题、方法和关联论文链接建议。
- 将需要更新判断的证据位置交给研究边际 Agent。

# 证据不足时

只报告实际阅读范围；缺少全文、附录或数据时写明哪些判断不能作出。
