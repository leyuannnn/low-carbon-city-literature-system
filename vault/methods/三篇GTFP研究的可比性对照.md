# 三篇 GTFP 研究的可比性对照（P01 / P02 / P08）

## 这张表回答什么

同一个低碳城市试点，P01 与 P02 报告 GTFP 显著为正，P08 报告单独低碳试点对 GTFP 的系数 `0.016` 且不显著。三篇都不是错论文，但**不能把三个系数排成"谁的效果更大"**。本表把三篇的样本、处理变量、GTFP 口径、对照组和估计量摊开，说明差异可能来自哪里，并给出可以判决这几种解释的检验。

关联：[[多期DID与GTFP测度比较]]（P01↔P02 的两两比较）、[[绿色-数字协同与低碳试点]]（研究边际）、[[2021-王亚飞-低碳试点与GTFP]]、[[2025-包玉香-黄河流域低碳试点与GTFP]]、[[2026-李兰冰-双试点政策与减排增效]]。

## 二、四个可能的差异来源

按"改动一处就足以翻转结论"的强度排序：

**① 对照组构成（最可能）**
P08 的单试点检验是**剔除全部大数据试验区城市之后**，再比较低碳试点城市与非试点城市（表 9 第 3–4 列，观测降至 3,184）。这意味着它的对照组里不含任何大数据试验区城市，处理组也不含双试点城市。P01、P02 从未控制这一重叠政策，其处理组中混有大数据试验区城市。**同一个"低碳试点"变量，三篇识别的其实不是同一批城市。**

**② GTFP 口径（次可能）**
P01 的非期望产出不含 CO₂，P02 含 CO₂。低碳试点直接约束的是碳，把碳放进非期望产出，政策效果更可能被"看见"；但约束收紧也可能压低当期效率。两篇都是 Malmquist 类指数，方向一致、口径不同，无法据此判定哪篇"更对"。

**③ 估计量与处理效应异质性**
P01 用系统 GMM（水平方程与差分方程并用），P02、P08 用双向固定效应。三个政策时点交错的情形下，若处理效应随队列或时间变化，双向固定效应会出现负权重，得到的系数可能偏离任何单个队列的真实效应。P01、P02 均未报告异质稳健估计量，P08 用合成 DID 缓解但未报告 Callaway-Sant'Anna 一类估计。

**④ 因变量形式与系数尺度**
三者都基于 Malmquist 类指数，但指数是链式还是累积、是否取对数、基准期如何设定，本次核读未逐项确认。**因此 `0.0926`、`0.157`、`0.321` 只能各自在本模型内解释，不能横向排序，也不能换算成"提高百分之几"来比较政策力度。**

## 三、可以判决这几种解释的检验

任何一条被验证，都会直接改变本项目的判断：

| 检验 | 做法 | 若结果如此，则说明 |
|---|---|---|
| A 口径 | 在 P08 的样本与处理定义下，把非期望产出改为含 CO₂ 重算 GTFP | 单试点系数升到接近 0.15 且显著 → 差异主要来自 GTFP 口径 |
| B 对照组 | 在 P02 的 50 市样本中剔除大数据试验区城市后重估 | 正效应消失 → 差异主要来自重叠政策与对照组 |
| C 估计量 | 对 P01、P02 样本改用 Callaway-Sant'Anna 或 Sun-Abraham 重估 | 系数衰减至不显著 → 原正效应部分是双向固定效应的权重问题 |
| D 区域 | 统一口径后加入"黄河流域×政策"交互项 | 交互项不显著 → "黄河流域更强"不成立，P02 的正效应是样本性的 |

这四条正是第二轮备忘录第 6 节"最小可行验证"的方法学底座；其中 B 与 D 是成本最低、最可能先做的两条。

## 四、据此可以说与不能说

**可以说**

1. 低碳试点是否提高 GTFP，**在三篇研究的样本与口径下结论不一致**，且不一致可以被样本构成、GTFP 口径、重叠政策和估计量四类原因解释。
2. 三篇一致的地方是：**绿色技术进步比绿色技术效率更容易被政策推动**（P01 东部 TC 为正、P02 TC 不显著而 EC 显著、P08 技术进步 `0.158***` 而技术效率不显著）。
3. P08 是目前唯一把"数字政策×低碳政策"组合与 GTFP 放进同一模型的文献，其结论是**单政策不足、组合才增效**。

**不能说**

1. 不能说"低碳试点提高 GTFP 已被证实"——P08 在剔除重叠政策后系数不显著。
2. 不能说"P08 推翻了 P01、P02"——三者识别的处理组不同，不是同一估计对象。
3. 不能说"黄河流域效果更强"——`0.157` 与 `0.0926` 不可比，且 P02 上中游不显著。
4. 不能把 P08 的"数字化"当作 AI 产业——其处理变量是国家级大数据综合试验区。

## 五、与 AI 结果的接口

P03 与 P05 都估计低碳试点对 AI 企业数量的影响（分别为平均正效应、以及二线/中部/技术层不显著的边界），**两篇都不估计 GTFP**；P08 估计 GTFP 但处理变量是政策组合，不估计 AI。因此本库中**没有任何一篇在同一模型、同一样本下同时估计 GTFP 与 AI 两个结果**——这正是本项目第二轮保留的研究边际，也是这张对照表最终要指向的空位。
