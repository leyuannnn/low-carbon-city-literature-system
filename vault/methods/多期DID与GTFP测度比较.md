# 多期 DID 与 GTFP 测度比较

## 最接近研究的可比性

| 维度 | [[2021-王亚飞-低碳试点与GTFP]] | [[2025-包玉香-黄河流域低碳试点与GTFP]] |
|---|---|---|
| 地理与时期 | 全国 221 城市，2005—2018 | 黄河流域回归样本 50 城市，2006—2019 |
| 观测数 | 3,094 | 700 |
| GTFP 方法 | 超效率 SBM-Malmquist | 超效率 SBM-GML |
| 非期望产出 | 废水、SO₂、粉尘烟尘 | 废水、SO₂、烟粉尘、CO₂ |
| 政策估计 | DID 框架 + 两步系统 GMM | 多期 DID，双向固定效应 |
| 绿色结果 | GTFP、EC、TC | GTFP、EC、TC |
| 关键结果 | 全国正；东部正，中西部负 | 全样本正；下游和大气污染防治重点区域更明显 |
| 主要识别检查 | 平行趋势、城市等级趋势、控制组和反事实时点 | 平行趋势、PSM-DID、安慰剂、排除其他政策 |
| 交错 DID 修正 | 未报告异质稳健估计量 | 未报告异质稳健估计量 |

## 对比较结论的影响

1. 两篇 GTFP 的污染指标不同，P02 额外纳入 CO₂，因此结果差异可能来自指标而非区域本身。
2. 两篇样本覆盖和估计方法不同，不能仅根据 `0.0926` 与 `0.157` 判断黄河流域政策效果“更强”。
3. P01 的区域分组显示中西部负效应，P02 的黄河流域全样本为正；二者并不必然冲突，因为“中西部”和“黄河流域城市群”不是同一分组，GTFP 口径也不同。
4. 后续最小验证应尽量统一城市样本、政策时点、GTFP 投入产出和估计量，再加入区域交互项，而不是继续比较来自不同模型的孤立系数。

## 机制核查提示

- P02：绿色创新为绿色专利占总专利比重，机制模型含交互项。
- P03：绿色创新为绿色专利申请总量，机制结果指向 AI 企业。
- P04：摘要披露绿色创新数量、质量和方向，方法细节待全文。
